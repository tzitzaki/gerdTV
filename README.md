# gerdTV

A multi-platform IPTV player (Flutter + Rust + libmpv) for Xtream Codes and M3U sources, with an EPG, TMDB enrichment, recording, casting and a watchdog that keeps streams playing. Targets macOS, Android TV, iPhone/iPad, Linux and Android phones.

- Install: `docs/INSTALL.md`
- Build: `docs/SETUP.md`
- Current state: `docs/HANDOVER.md`
